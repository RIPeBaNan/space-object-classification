# Space Object Classification

Учебный проект по многоклассовой классификации астрономических объектов: **галактик, квазаров и звёзд**.

## Результат

На отложенной тестовой выборке итоговая модель **SVC с RBF-ядром** получила:
- **F1-macro: 0.9430**
- Accuracy: 0.966
- F1-macro на кросс-валидации: 0.9448

Метрики взяты из сохранённых результатов `space_object_classification.ipynb`, а не из повторного запуска.

## Данные и задача

Датасет содержит **15 000 наблюдений**. Задача — предсказать класс космического объекта по его признакам.

Датасет не публикуется. Для локального запуска разместите приватный файл по пути `data/space_data.csv`.

## Подход

- Исследовательский анализ и подготовка данных
- Разделение на обучающую и тестовую выборки
- `Pipeline` с `MinMaxScaler` для предотвращения утечки при кросс-валидации
- Сравнение базовой логистической регрессии, L1/L2-регуляризации и SVC (RBF)
- Подбор гиперпараметров через `GridSearchCV` и `StratifiedKFold`
- Оценка качества по `F1-macro`, отчёту классификации и матрице ошибок

## Запуск

1. Установить Python 3.10+.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Открыть `space_object_classification.ipynb` в Jupyter.
4. Запустить ячейки последовательно. Для загрузки датасета требуется интернет.
